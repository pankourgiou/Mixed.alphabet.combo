some words about Cern:
Το CERN δεν εφάρμοσε ολόκληρο το Internet (το οποίο προϋπήρχε ως δίκτυο υπολογιστών και πρωτόκολλα όπως το TCP/JP από τις δεκαετίες του 1960 και 1970), αλλά εφηύρε το World Wide Web (WWW), δηλαδή τον τρόπο με τον οποίο σερφάρουμε και βλέπουμε πληροφορίες πάνω στο Internet.

Βασικά σημεία σύνδεσης CERN και Web:

• Η γέννηση (1989): Ο Βρετανός επιστήμονας Tim Berners-Lee εργαζόταν στο CERN όταν συνέδεσε την ιδέα του υπερκεειμένου (hypertext) με το Internet για να διευκολύνει την ανταλλαγή πληροφοριών και ερευνών ανάμεσα σε επιστήμονες παγκοσμίως.
• Οι τεχνολογίες που δημιουργήθηκαν στο CERN:
	• Η γλώσσα HTML (HyperText Markup Language)
	• Το πρωτόκολλο επικοινωνίας HTTP (HyperText Transfer Protocol)
	• Ο πρώτος web browser (πρόγραμμα περιήγησης) και ο πρώτος web server
	• Η πρώτη ιστοσελίδα στον κόσμο (info.cern.ch) το 1990/1991.
• Δωρεάν σε όλους (1993): Στις 30 Απριλίου 1993, το CERN αποφάσισε να διαθέσει την τεχνολογία του Web δωρεάν στο κοινό (open source / public domain), χωρίς δικαιώματα ή πατέντες, επιτρέποντας την εκρηκτική παγκόσμια εξάπλωσή του
